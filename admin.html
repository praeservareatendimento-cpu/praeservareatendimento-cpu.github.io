Painel do site

Abra os arquivos do site (index.html, produtos.html e oportunidade.html) para começar a editar os textos e as imagens.

Dica: deixe o admin.html na mesma pasta das páginas do site para ele abrir tudo sozinho.

Entrar para publicar

Digite a senha definida no arquivo save.php.

Salvar na pasta do site

Para salvar direto no seu computador, escolha a pasta do site: a mesma onde estão o index.html e o admin.html. O navegador vai pedir permissão para editar os arquivos dessa pasta.

Isso é pedido no primeiro salvamento sempre que o painel é aberto. Antes de salvar, o painel guarda uma cópia da versão anterior de cada página na pasta backups.

Conectar ao GitHub

Para o botão Salvar alterações publicar direto no site, o painel precisa de uma chave de acesso da conta do GitHub onde o site está. Ela fica guardada só neste navegador. Faça isso uma vez em cada computador.

  1. Com a conta do site aberta no GitHub, clique em criar a chave de acesso ↗. O nome, a validade e a permissão já vêm preenchidos.
  2. Em Repository access, marque Only select repositories e escolha o repositório do site.
  3. Confira se Contents está como Read and write, clique em Generate token e copie a chave (começa com github_pat_).
  4. Cole a chave abaixo e clique em Conectar.

Como usar o painel

Editar

  • Escolha a página no topo do painel (Página inicial, Produtos ou Seja consultor). Os campos estão separados pelas seções. Use a busca para achar um texto rápido.
  • Campos marcados com “Em 3 páginas” (WhatsApp, logo, menu, rodapé, certificações…) aparecem em todas as páginas: a mudança vale para todas.
  • Com “Clicar no site abre o campo” desligado, os links e as abas da prévia funcionam como no site (dá para ir de uma página para outra).
  • Na página Produtos, cada categoria tem os botões para adicionar, remover (lixeira) e mudar a ordem (setas) dos produtos.
  • Importar conteúdo copia textos e imagens de um arquivo antigo do site para a versão atual.
  • Clique em qualquer texto ou foto na prévia para ir direto ao campo.
  • Nos textos com dica de negrito, escreva **assim** para destacar.
  • Suas alterações ficam guardadas como rascunho neste navegador até você publicar ou baixar.

Imagens

  • Do computador: clique em “Enviar do computador” ou arraste a foto para o quadrado. O painel reduz e otimiza a imagem automaticamente.
  • Da internet: cole o endereço direto da imagem. No navegador, clique com o botão direito na foto e escolha “Copiar endereço da imagem”.
  • Fotos por link dependem do site de origem. Se ele apagar a imagem, ela some do seu site também.
